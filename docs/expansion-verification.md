The backup defect was fixed by using authoritative live object inventory: a historical logical attachment whose underlying object has already been garbage-collected is not a missing live object. A real upload/delete/GC/backup regression retains failure for genuinely missing ready objects. The load harness records raw failures separately from eventual outcomes and uses stable IDs with bounded retries consistent with the production client's 5xx handling.

The first 1,000 burst exposed an Auth classification defect: temporary identity-provider failures were returned as permanent `AUTH_REQUIRED`. Infrastructure failures now return retryable `SERVICE_UNAVAILABLE`, with a bounded identity-check deadline; verified revoked/deleted sessions still return `AUTH_REQUIRED`. An actual controlled outage/recovery and invalid-session regression passed. A further stress run with separately reported bounded recovery of the original commands remains pending. The original failed burst is preserved and is not a hosted capacity claim.

The first observer also found a navigation race: a late initial project-link resolution could overwrite a newer navigation choice. App now checks the current URL before publishing that result. The observer now journals each measured save, uses bounded action timeouts and writes a unique report for every run.
