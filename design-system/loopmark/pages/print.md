# Bag label exception

Print uses white paper and black ink, with no shadows, navigation, buttons, or background texture. Include project name, readable project code, craft, tool size, row/repeat, next step, and optional QR code. Label content must be self-contained even if the QR cannot be opened. QR is only a shortcut into the current device/origin’s local app record; the app must say it does not transfer or back up a project. Allow long names/instructions to wrap. Do not shrink essential text below 11pt to fit an arbitrary label size. The print preview must match the actual printed fields.
